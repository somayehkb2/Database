# Database Connection & Management

تمرین‌ها و پروژه‌های مربوط به اتصال برنامه‌های پایتون به پایگاه داده.

## امکانات
- اتصال به دیتابیس‌های مختلف (SQLite, MySQL, PostgreSQL)
- انجام عملیات CRUD (ایجاد، خواندن، به‌روزرسانی، حذف)
- مدیریت جداول و روابط با کد
